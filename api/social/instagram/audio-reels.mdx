Fetches the reels Instagram exposes for an audio page like instagram.com/reels/audio/{audio_id}/. Pass the audio\_id from that URL. Use cursor from the previous response to request the next page when Instagram returns one.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/instagram/audio/reels
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `audio_id` | Yes | The audio id from the Instagram audio page URL. |
| `cursor` | No | Pagination cursor returned by Instagram from the previous response. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/instagram/audio/reels?audio_id=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
