Returns the raw HTML embed snippet for an Instagram user's profile widget. The response contains a single html string that can be inserted into a webpage to render an embeddable Instagram profile card. Requires the user's handle as input.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/instagram/user/embed
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `handle` | Yes | Instagram handle |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/instagram/user/embed?handle=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
