Retrieves comments on a public Instagram post or reel. Each comment includes the comment text, creation timestamp, and commenter details such as username, user ID, verification status, and profile picture URL. Supports cursor-based pagination to load additional comment pages.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v2/instagram/post/comments
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | Yes | The URL of the post or reel to get comments from |
| `cursor` | No | The cursor to get more comments. Get 'cursor' from previous response. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v2/instagram/post/comments?url=https://example.com" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
