Returns a paginated feed of a user's public Instagram posts, including reels, photos, videos, and carousels. Each item includes media type, shortcode, caption text, like count, comment count, play count, video URLs, image URLs, and tagged users. Play counts reflect Instagram-only views and exclude cross-posted Facebook views. Supports cursor-based pagination via next\_max\_id for scrolling through the full timeline.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v2/instagram/user/posts
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `handle` | Yes | Instagram handle |
| `next_max_id` | No | Cursor to get next page of results. |
| `trim` | No | Set to true to get a trimmed response |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v2/instagram/user/posts?handle=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
