Searches Google for public Instagram results matching a keyword or phrase, then returns matching public profiles. Profile-page matches are marked matched_from=profile. Reel/post caption matches are enriched into the creator profile and marked matched_from=caption. This is best-effort and depends on what Google has indexed; it is not a complete native Instagram profile search.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/instagram/search/profiles
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `query` | Yes | Bio or caption keyword/phrase to search for. |
| `cursor` | No | The cursor returned by the previous response. In this version, it is the next Google results page number. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/instagram/search/profiles?query=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
