Fetches public Kwai post details including caption, media URLs, cover images, counts, author info, and music metadata. Uses Kwai's public web API endpoint, not HTML scraping.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/kwai/post
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | No | Kwai post URL |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/kwai/post" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
