Fetches public Kwai profile data including username, bio, avatar, verification status, gender, and public counts. Uses Kwai's public web API endpoint, not HTML scraping.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/kwai/profile
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `handle` | No | Kwai profile handle. Use this or url. |
| `url` | No | Kwai profile URL. Use this or handle. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/kwai/profile" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
