Fetches a paginated list of public Kwai posts for a user, including captions, media URLs, covers, counts, author info, and the next cursor when more results are available. Uses Kwai's public web API endpoint, not HTML scraping.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/kwai/user/posts
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `handle` | No | Kwai profile handle. Use this or url. |
| `url` | No | Kwai profile URL. Use this or handle. |
| `cursor` | No | Cursor from the previous response for the next page |
| `count` | No | Number of posts to return, max 50 |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/kwai/user/posts" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
