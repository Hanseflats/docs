Fetches detailed metadata for a specific TikTok sound or song by its clipId. Returns `music_info` with `title`, `author`, `album`, `duration`, `user_count` (number of videos using this sound), `play_url`, cover art, and artist details. Use the `clipId` from a sound URL or from the popular songs endpoint.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/tiktok/song
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `clipId` | Yes | This is a little confusing because this isn't songId like you'd think. It is the clipId. I guess because you can clip different portions of a song 🤷‍♂️ |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/tiktok/song?clipId=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
