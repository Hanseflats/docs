Searches for TikTok videos by keyword or phrase — the general video search across all of TikTok. Returns `search_item_list`, an array of objects each containing `aweme_info` with `aweme_id`, `desc` (caption), `statistics` (play\_count, digg\_count/likes, comment\_count, share\_count), `video` info, and `author` details. Paginate with `cursor`. TikTok may return duplicate results.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/tiktok/search/keyword
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `query` | Yes | Keyword to search for |
| `date_posted` | No | Time Frame Enum: yesterday, this-week, this-month, last-3-months, last-6-months, all-time. |
| `sort_by` | No | Sort by Enum: relevance, most-liked, date-posted. |
| `region` | No | Note, this doesn't filter the tiktoks only in a specfic region, it puts the proxy there. Use it in case you want to scrape posts only available for some country. Use 2 letter country codes like US, GB, FR, etc |
| `cursor` | No | Cursor to get more videos. Get 'cursor' from previous response. |
| `trim` | No | Set to true to get a trimmed response |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/tiktok/search/keyword?query=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
