Retrieves the following list — accounts that a TikTok user follows — by their handle. Returns `followings`, an array of user objects each with `nickname`, `unique_id`, `uid`, `follower_count`, `following_count`, `signature`, and avatar URLs; also returns `total` count. Paginate with `min_time` from the previous response.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/tiktok/user/following
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `handle` | Yes | TikTok handle |
| `min_time` | No | Used to paginate. Get 'min\_time' from previous response. |
| `trim` | No | Set to true to get a trimmed response |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/tiktok/user/following?handle=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
