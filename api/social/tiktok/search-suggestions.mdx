Gets the autocomplete suggestions TikTok shows while someone is typing in search. Returns `suggestions`, a clean array of suggested search terms and the most useful metadata for each suggestion.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/tiktok/search/suggestions
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `query` | Yes | Search query to get suggestions for |
| `region` | No | Region code for suggestions |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/tiktok/search/suggestions?query=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
