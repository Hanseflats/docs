Retrieves the follower list of a TikTok account by handle or user_id — useful for seeing who follows a creator or getting subscriber data. Returns `followers`, an array of user objects each with `nickname`, `unique_id`, `uid`, `follower_count`, `following_count`, and avatar URLs; also returns `total` follower count. Paginate with `min_time` from the previous response.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/tiktok/user/followers
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `handle` | No | TikTok handle |
| `user_id` | No | User id. Use this for faster response times. |
| `min_time` | No | Used to paginate. Get 'min_time' from previous response. |
| `trim` | No | Set to true to get a trimmed response |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/tiktok/user/followers" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
