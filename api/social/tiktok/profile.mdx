Fetches public profile data for a TikTok user by their handle or user_id — useful for looking up a creator's identity, bio, and account stats. Returns a `user` object (display name, avatar URLs, bio/signature, verification status, bio link) and a `stats` object (followerCount, followingCount, heartCount/total likes, videoCount). This only returns profile metadata, not the user's actual videos or followers list.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/tiktok/profile
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `handle` | No | TikTok handle. You can pass handle or user_id. |
| `user_id` | No | TikTok user id. |
| `cache_max_age` | No | If we have a response in the cache that is this many days old or newer, return the cached response (0 credits, with 'cached': true and a 'cached_at' timestamp). Otherwise, scrape a live result (1 credit). [See the Caching page for details.](https://docs.scrapecreators.com/caching) Enum: 1d, 3d, 7d, 14d, 30d. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/tiktok/profile" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
