Fetches customer reviews for a TikTok Shop product by URL or product_id. Returns `product_reviews`, an array of review objects each with `rating`, `display_text`, `review_timestamp_fmt`, `review_user` (name, avatar), and `sku_specification` (variant purchased); also returns `total_reviews` count and `rating_distribution`. Paginate with `page`.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/tiktok/shop/product/reviews
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | No | The URL of the product (required if product_id is not provided) |
| `product_id` | No | The ID of the product (required if url is not provided) |
| `region` | No | The region of the product. US is the reliable region right now; non-US regions should not be considered reliable and may return limited or inconsistent review data. Sorry for the inconvenience. |
| `page` | No | The page number of the reviews |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/tiktok/shop/product/reviews" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
