Discovers trending and popular TikTok creators, filterable by follower count range, creator country, and audience country. Returns `creator_list`, an array of creator objects each with `nickname`, `unique_id`, `follower_count`, `likes_count`, `video_views`, `engagement_rate`, and avatar URLs. Sortable by engagement, follower count, or average views.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/tiktok/creators/popular
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `page` | No | Page number |
| `sortBy` | No | Sort creators by engagement, follower count, or average views Enum: engagement, follower, avg\_views. |
| `followerCount` | No | Filter by follower count range Enum: 10K-100K, 100K-1M, 1M-10M, 10M\+. |
| `creatorCountry` | No | Country code of the creator Enum: AU, BR, CA, EG, FR, DE, ID, IL, IT, JP, MY, PH, RU, SA, SG, KR, ES, TW, TH, TR, AE, GB, US, VN. |
| `audienceCountry` | No | Country code of the audience/follower Enum: AU, BR, CA, EG, FR, DE, ID, IL, IT, JP, MY, PH, RU, SA, SG, KR, ES, TW, TH, TR, AE, GB, US, VN. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/tiktok/creators/popular" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
