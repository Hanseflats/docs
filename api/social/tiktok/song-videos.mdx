Fetches TikTok videos that use a specific sound or song, identified by its clipId. Returns `aweme_list`, an array of video objects each with `aweme_id`, `desc` (caption), `statistics` (play\_count, digg\_count/likes, comment\_count, share\_count), `video` info, and `author` details. Paginate with `cursor` from the previous response.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/tiktok/song/videos
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `clipId` | No | This is clipId. Can be found on a url like so: [https://www.tiktok.com/music/That%27s-Who-I-Praise-7370375686554782506](https://www.tiktok.com/music/That%27s-Who-I-Praise-7370375686554782506), where 7370375686554782506 is the clipId |
| `cursor` | No | The cursor to get the next page of results. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/tiktok/song/videos" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
