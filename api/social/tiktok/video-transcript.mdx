Extracts the transcript, captions, or subtitles from a TikTok video by URL. Returns `id`, `url`, and `transcript` as a WEBVTT-formatted string with timestamped text segments. Video must be under 2 minutes; costs an additional 10 credits when `use_ai_as_fallback=true`.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/tiktok/video/transcript
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | Yes | TikTok video URL |
| `language` | No | Language of the transcript. 2 letter language code, ie 'en', 'es', 'fr', 'de', 'it', 'ja', 'ko', 'zh' |
| `use_ai_as_fallback` | No | Set to 'true' to use AI as a fallback to get the transcript if the transcript is not found. Costs 10 credits to use this feature. And only if the video is under 2 minutes. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/tiktok/video/transcript?url=https://example.com" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Credits

**2 Lens credits** per upstream credit charged (~**2¢** typical). Cache hits are **free**.
