Returns the TikTok region code for a public profile, like `US` for United States or `MX` for Mexico.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/tiktok/profile/region
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `handle` | Yes | TikTok handle |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/tiktok/profile/region?handle=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
