Searches for TikTok users by keyword or name — useful for finding creators or accounts matching a query. Returns `users`, an array of objects each containing `user_info` (nickname, unique_id, signature/bio, follower_count, following_count, avatar) and associated `items`. Paginate with `cursor` from the previous response.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/tiktok/search/users
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `query` | Yes | Search query for users |
| `cursor` | No | Cursor to get more users. Get 'cursor' from previous response. |
| `trim` | No | Set to true to get a trimmed response |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/tiktok/search/users?query=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
