Searches TikTok Shop for products matching a keyword query. Returns an array of product objects each with `title`, `cover` image, `url` (product page link), `price`, `sold_count`, `review_count`, `rating`, and `shop_name`. Paginate with `page`; filter by region.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/tiktok/shop/search
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `query` | Yes | Term you want to search for |
| `page` | No | Page number to retrieve |
| `region` | No | Region to search shop products in. Non-US TikTok Shop regions are not reliable right now and may return limited or inconsistent results. Sorry for the inconvenience. Enum: US, GB, DE, FR, IT, ID, MY, MX, PH, SG, ES, TH, VN, BR, JP, IE. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/tiktok/shop/search?query=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
