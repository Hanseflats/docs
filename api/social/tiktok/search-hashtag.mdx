Searches for TikTok videos under a specific hashtag — useful for finding content by topic or trend. Returns `aweme_list`, an array of video objects each with `aweme_id`, `desc` (caption), `statistics` (play_count, digg_count/likes, comment_count, share_count), `video` info, and `author` details. Paginate with `cursor` from the previous response. TikTok may return duplicate results.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/tiktok/search/hashtag
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `hashtag` | Yes | Hashtag to search for (without #) |
| `region` | No | Region the proxy will be set to. Note: this isn't going to grab you all tiktoks from this region, you're just setting the proxy there. |
| `cursor` | No | Cursor to get more videos. Get 'cursor' from previous response. |
| `trim` | No | Set to true to get a trimmed response |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/tiktok/search/hashtag?hashtag=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
