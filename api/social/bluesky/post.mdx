Fetches a single Bluesky post by URL, returning the post's record text, author info, embed content, replyCount, repostCount, likeCount, and quoteCount. Also includes a replies array with threaded reply posts.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/bluesky/post
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | Yes | Bluesky post URL |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/bluesky/post?url=https://example.com" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
