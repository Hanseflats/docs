Fetches public ads for a company from the Google Ad Transparency Library by domain or advertiser_id. Each ad includes advertiserId, creativeId, format, adUrl, advertiserName, domain, firstShown, and lastShown. Costs 25 credits per request when get_ad_details=true; without it, only advertiserId and creativeId are returned at 1 credit.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/google/company/ads
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `domain` | No | The domain of the company |
| `advertiser_id` | No | The advertiser id of the company |
| `topic` | No | The topic to search for. If you search for 'political', you will also need to pass a 'region', like 'US' or 'AU' Enum: all, political. |
| `region` | No | The region to search for. Defaults to anywhere |
| `start_date` | No | Start date to search for. Format: YYYY-MM-DD |
| `end_date` | No | End date to search for. Format: YYYY-MM-DD |
| `platform` | No | Platform to search for. Enum: google_maps, google_play, google_search, google_shopping, youtube. |
| `format` | No | Ad format to search for. Enum: text, image, video. |
| `get_ad_details` | No | Set to true to get the ad details. Will cost 25 credits. |
| `cursor` | No | Cursor to paginate through results |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/google/company/ads" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Credits

**0.5 Lens credits** per upstream credit charged (~**2¢** typical). Cache hits are **free**.
