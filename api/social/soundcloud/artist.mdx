Fetches detailed information about a SoundCloud artist by its handle or URL. Returns artist metadata including id, name, followers, etc

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/soundcloud/artist
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `handle` | No | SoundCloud artist handle. If you'd prefer to use the URL instead, you can use the url parameter instead. |
| `url` | No | SoundCloud artist URL. If you'd prefer to use the handle instead, you can use the handle parameter instead. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/soundcloud/artist" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
