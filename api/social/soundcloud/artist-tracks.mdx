Fetches tracks/songs for a SoundCloud artist by handle or URL. Returns the artist profile, track list, and pagination info from SoundCloud.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/soundcloud/artist/tracks
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `handle` | No | SoundCloud artist handle. If you'd prefer to use the URL instead, you can use the url parameter instead. |
| `url` | No | SoundCloud artist tracks URL. If you'd prefer to use the handle instead, you can use the handle parameter instead. |
| `cursor` | No | Cursor to get more tracks. Get 'cursor' from previous response. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/soundcloud/artist/tracks" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
