Fetches a paginated list of pins from a Pinterest board by URL, returning each pin's id, description, title, images, board info, pin\_join annotations, and aggregated\_pin\_data. Supports pagination via cursor and a trim option for lighter responses.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/pinterest/board
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | Yes | The URL of the board to get |
| `cursor` | No | The cursor to get the next page of results |
| `trim` | No | Set to true for a trimmed down version of the response |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/pinterest/board?url=https://example.com" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
