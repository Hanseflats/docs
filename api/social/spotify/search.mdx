Search Spotify for tracks, artists, albums, episodes, podcasts, and audiobooks. Use type=podcasts when you need podcast ids for the podcast endpoints.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/spotify/search
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `query` | Yes | Search query |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/spotify/search?query=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
