Returns episodes for a Spotify podcast. Pass the cursor returned by a response to get the next page.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/spotify/podcast/episodes
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `id` | No | Spotify podcast id. If you'd prefer to use the URL instead, you can use the url parameter instead. |
| `url` | No | Spotify podcast URL. If you'd prefer to use the id instead, you can use the id parameter instead. |
| `cursor` | No | Cursor returned by the previous response. Omit for the first page. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/spotify/podcast/episodes" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
