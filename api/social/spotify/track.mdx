Retrieves detailed information about a Spotify track by its id or URL, including track metadata, artists, album info, duration, playability, and sharing details.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/spotify/track
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `id` | No | Spotify track id. If you'd prefer to use the URL instead, you can use the url parameter instead. |
| `url` | No | Spotify song URL. If you'd prefer to use the id instead, you can use the id parameter instead. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/spotify/track" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
