Retrieves detailed information about a Spotify album by its id or URL, including album metadata, artists, release date, cover art, copyright info, tracks, and sharing details.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/spotify/album
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `id` | No | Spotify album id. If you'd prefer to use the URL instead, you can use the url parameter instead. |
| `url` | No | Spotify album URL. If you'd prefer to use the id instead, you can use the id parameter instead. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/spotify/album" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
