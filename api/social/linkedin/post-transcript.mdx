Fetches the transcript from a LinkedIn post video when LinkedIn exposes one publicly. Returns null with transcriptNotAvailable when the post has no transcript, and only deducts credits when a transcript is returned.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/linkedin/post/transcript
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | Yes | The URL of the LinkedIn post to get the transcript from |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/linkedin/post/transcript?url=https://example.com" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Credits

**0.5 Lens credits** per upstream credit charged (~**2¢** typical). Cache hits are **free**.

See [Social API overview](/api/social) and [Linkedin](/api/social/linkedin).
