Finds public LinkedIn posts, feed updates, and Pulse articles by keyword using Google Search, then returns post details such as description, author, media, images, like count, comment count, and published date when LinkedIn exposes them publicly. Results depend on what Google has indexed, so this is best-effort and not a complete LinkedIn-native search. Use date_posted for recent posts and pass the returned cursor to fetch the next page.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/linkedin/search/posts
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `query` | Yes | Keyword or phrase to search for in public LinkedIn posts |
| `date_posted` | No | Date posted filter based on Google-indexed results Enum: last-hour, last-day, last-week, last-month, last-year. |
| `cursor` | No | The cursor returned from the previous response |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/linkedin/search/posts?query=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
