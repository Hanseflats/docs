Searches the LinkedIn Ad Library by company name, keyword, or companyId with optional country and date filters. Each ad includes id, description, headline, adType, advertiser, targeting details, image or video URLs, totalImpressions, and impressionsByCountry. Supports pagination via paginationToken.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/linkedin/ads/search
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `company` | No | The company name to search for. 'Microsoft' for example |
| `keyword` | No | The keyword to search for |
| `companyId` | No | The company id to search for |
| `countries` | No | Comma separated list of countries. Example: US,CA,MX |
| `startDate` | No | Start date to search for. Format: YYYY-MM-DD |
| `endDate` | No | End date to search for. Format: YYYY-MM-DD |
| `paginationToken` | No | Pagination token to paginate through results |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/linkedin/ads/search" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
