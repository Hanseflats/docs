Retrieves paginated posts from a LinkedIn company page, including each post's URL, ID, publication date, and full text content. Supports page-based pagination up to a maximum of 7 pages due to a LinkedIn platform limitation.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/linkedin/company/posts
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | Yes | The URL of the LinkedIn company page to get |
| `page` | No | The page number to get |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/linkedin/company/posts?url=https://example.com" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
