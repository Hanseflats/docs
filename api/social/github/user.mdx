Retrieves public GitHub user details including name, bio, avatar, company, location, blog, follower counts, public repo counts, and account timestamps. Pass username, handle, or a full GitHub user url.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/github/user
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `handle` | No | GitHub username/handle of the user you want the details for |
| `url` | No | GitHub user URL, e.g. [https://github.com/torvalds](https://github.com/torvalds). |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/github/user" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
