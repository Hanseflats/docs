Scrapes GitHub's public Trending repositories page. Returns ranked repositories with public URLs, descriptions, language, star/fork counts, stars for the selected range, and built-by users when GitHub shows them. Use language for paths like JavaScript or Python, since for daily/weekly/monthly, and spoken_language_code for GitHub's spoken language filter.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/github/trending/repositories
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `language` | No | Optional coding language, e.g. javascript, python, or go. |
| `since` | No | Trending range: daily, weekly, or monthly. Defaults to daily. Enum: daily, weekly, monthly. |
| `spoken_language_code` | No | Optional spoken language code filter, e.g. en. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/github/trending/repositories" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
