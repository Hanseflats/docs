Retrieves public GitHub followers for a user. Each follower includes login, avatar, user URL, type, and GitHub IDs. Pass username, handle, or a full GitHub user url. Supports cursor pagination.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/github/user/followers
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `handle` | No | GitHub username/handle of the user you want the followers for |
| `url` | No | GitHub user URL, e.g. https://github.com/torvalds. |
| `cursor` | No | Cursor from the previous response. Defaults to 1. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/github/user/followers" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
