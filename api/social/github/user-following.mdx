Retrieves public accounts followed by a GitHub user. Each account includes login, avatar, profile URL, type, and GitHub IDs. Pass username, handle, or a full GitHub profile url. Supports cursor pagination.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/github/user/following
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `handle` | No | GitHub handle |
| `url` | No | GitHub profile URL |
| `cursor` | No | Cursor from the previous response. Defaults to 1. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/github/user/following" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
