Retrieves a user's public repositories with repo metadata like description, language, stars, forks, topics, license, visibility, default branch, and timestamps. Pass username, handle, or url. Supports pagination with cursor, plus GitHub's type, sort, and direction parameters.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/github/user/repositories
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `handle` | No | GitHub username/handle of the user you want the repositories for |
| `url` | No | GitHub user URL, e.g. [https://github.com/kentcdodds](https://github.com/kentcdodds). |
| `type` | No | Repository type. Defaults to owner. GitHub also supports all and member. Enum: owner, all, member. |
| `sort` | No | Sort by created, updated, pushed, or full\_name. Defaults to updated. Enum: created, updated, pushed, full\_name. |
| `direction` | No | Sort direction: ascending or descending. Enum: asc, desc. |
| `cursor` | No | Cursor from the previous response. Defaults to 1. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/github/user/repositories" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
