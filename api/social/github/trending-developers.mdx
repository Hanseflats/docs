Scrapes GitHub's public Trending developers page. Returns ranked developers with username, name, public profile URL, avatar, and the popular repository GitHub shows for that developer when available. Use language for paths like javascript or python and since for daily/weekly/monthly.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/github/trending/developers
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `language` | No | Optional trending coding language, e.g. javascript, python, or go. |
| `since` | No | Trending range: daily, weekly, or monthly. Defaults to daily. Enum: daily, weekly, monthly. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/github/trending/developers" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
