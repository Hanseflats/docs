Searches for Threads users by username, returning matching profiles with username, full_name, profile_pic_url, is_verified, and pk. Useful for finding user accounts before fetching their profile or posts.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/threads/search/users
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `query` | Yes | Username to search for |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/threads/search/users?query=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
