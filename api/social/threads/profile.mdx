Retrieves a Threads user's public profile including username, full\_name, biography, profile\_pic\_url, follower\_count, is\_verified, bio\_links, and hd\_profile\_pic\_versions. Also indicates whether the account is a threads-only user via is\_threads\_only\_user.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/threads/profile
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `handle` | Yes | Threads username |
| `cache_max_age` | No | If we have a response in the cache that is this many days old or newer, return the cached response (0 credits, with 'cached': true and a 'cached\_at' timestamp). Otherwise, scrape a live result (1 credit). [See the Caching page for details.](https://docs.scrapecreators.com/caching) Enum: 1d, 3d, 7d, 14d, 30d. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/threads/profile?handle=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
