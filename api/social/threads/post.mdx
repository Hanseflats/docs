Fetches a single Threads post by URL, returning the post's caption, like\_count, view\_counts, reshare\_count, direct\_reply\_count, image\_versions2, and taken\_at. Also includes comments and related\_posts arrays. Supports a trim option for lighter responses.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/threads/post
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | Yes | The URL of the post to get |
| `trim` | No | Set to true for a trimmed down version of the response |
| `cache_max_age` | No | If we have a response in the cache that is this many days old or newer, return the cached response (0 credits, with 'cached': true and a 'cached\_at' timestamp). Otherwise, scrape a live result (1 credit). [See the Caching page for details.](https://docs.scrapecreators.com/caching) Enum: 1d, 3d, 7d, 14d, 30d. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/threads/post?url=https://example.com" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
