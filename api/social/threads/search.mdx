Searches Threads for posts matching a keyword, returning up to 10 results with caption text, like_count, reshare_count, direct_reply_count, user info, and image_versions2. Supports optional start_date and end_date filters plus a trim option. Only 10 results are returned per request due to public API limitations.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/threads/search
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `query` | Yes | Keyword to search for |
| `start_date` | No | Start date to search for |
| `end_date` | No | End date to search for |
| `trim` | No | Set to true for a trimmed down version of the response |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/threads/search?query=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
