Experimental endpoint. Checks a YouTube video for the paid-promotion disclosure and infers likely sponsors/promoted brands from the public description, description links, promo-code text, and transcript. YouTube tells us that a video contains paid promotion, but it does not always tell us the sponsor directly, so this endpoint returns suspected sponsors with confidence and evidence. This is inferred, not an official YouTube sponsor field. Feedback welcome: support@Lens Social API.com

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/youtube/video/sponsors
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | Yes | YouTube video or short URL |
| `language` | No | 2 letter language code used for transcript lookup, ie 'en', 'es', 'fr' etc. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/youtube/video/sponsors?url=https://example.com" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
