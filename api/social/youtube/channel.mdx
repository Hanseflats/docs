Retrieves comprehensive YouTube channel profile data including name, avatar images, subscriber count (subscribers), total video and view counts, join date, tags, and linked social accounts like Twitter and Instagram. Accepts a channelId, handle, or full channel URL as input. Returns channel metadata such as country, email, and external store links when available.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/youtube/channel
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `channelId` | No | YouTube channel ID. Can pass a channelId, handle or url |
| `handle` | No | YouTube channel handle. Can pass a channelId, handle or url |
| `url` | No | YouTube channel URL. Can pass a channelId, handle or url |
| `cache_max_age` | No | If we have a response in the cache that is this many days old or newer, return the cached response (0 credits, with 'cached': true and a 'cached_at' timestamp). Otherwise, scrape a live result (1 credit). [See the Caching page for details.](https://docs.scrapecreators.com/caching) Enum: 1d, 3d, 7d, 14d, 30d. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/youtube/channel" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
