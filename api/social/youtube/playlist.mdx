Retrieves all videos in a YouTube playlist, including the playlist title, owner info, total video count, and each video's title, URL, thumbnail, duration, and channel. Accepts the playlist ID found in the 'list' URL parameter.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/youtube/playlist
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `playlist_id` | Yes | The ID of the YouTube playlist. In the YouTube URL it will be the 'list' parameter. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/youtube/playlist?playlist_id=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
