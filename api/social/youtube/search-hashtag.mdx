Searches YouTube for content matching a specific hashtag and returns matching videos with title, URL, thumbnail, view count (views), publish date, duration, and channel info. Supports pagination via continuationToken and filtering to return all content types or only shorts.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/youtube/search/hashtag
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `hashtag` | Yes | Hashtag to search for |
| `continuationToken` | No | Continuation token to get more videos. Get 'continuationToken' from previous response. |
| `type` | No | Search for all types of content or only shorts Enum: all, shorts. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/youtube/search/hashtag?hashtag=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
