Fetches comments and replies from a YouTube video, including each comment's text content, author details, like count, reply count, and publish date. Supports ordering by top or newest, and paginating with continuationToken. Limited to approximately 1,000 top comments or 7,000 newest comments.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/youtube/video/comments
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | Yes | YouTube video URL |
| `continuationToken` | No | Continuation token to get more comments. Get 'continuationToken' from previous response. |
| `order` | No | Order of comments Enum: top, newest. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/youtube/video/comments?url=https://example.com" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
