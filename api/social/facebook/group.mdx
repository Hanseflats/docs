Fetches the public information shown on a Facebook group's About page, including its description, privacy and visibility, member and activity counts, categories, administrators and moderators when Facebook exposes them, group history, and rules. Provide either url or group_id.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/facebook/group
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | No | The Facebook group URL. Group sub-page URLs such as /about work too. |
| `group_id` | No | The numeric Facebook group ID. Provide this instead of url if you already have it. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/facebook/group" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
