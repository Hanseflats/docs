Fetches up to 10 reels per request from a public Facebook page. Each reel includes id, url, view\_count, description, creation\_time, video\_url, thumbnail, play\_time\_in\_ms, and music details. Pagination requires passing both next\_page\_id and cursor from the previous response.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/facebook/profile/reels
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | Yes | Facebook page URL |
| `next_page_id` | No | To paginate through to the next page |
| `cursor` | No | To paginate through to the next page |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/facebook/profile/reels?url=https://example.com" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
