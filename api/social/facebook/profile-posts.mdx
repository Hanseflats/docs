Returns publicly visible Facebook profile posts, limited to 3 posts per page due to API limitations. Each post includes id, text, url, reactionCount, commentCount, publishTime, videoDetails with sdUrl, hdUrl, and thumbnailUrl, plus topComments. Accepts either a url or pageId parameter, where pageId is faster.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/facebook/profile/posts
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | No | Facebook profile URL |
| `pageId` | No | Facebook profile page id |
| `cursor` | No | To paginate through the posts |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/facebook/profile/posts" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
