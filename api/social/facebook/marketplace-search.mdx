Searches Facebook Marketplace listings by keyword and lat/lng. Supports pagination with the returned cursor. Pass the cursor value back as-is. When sort\_by is creation\_time\_descend, Facebook can still return slightly different ordering between identical requests. For alerting/new-item workflows, scrape multiple pages and dedupe by listing id instead of relying on page 1 item order being identical every run.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/facebook/marketplace/search
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `query` | Yes | Search keyword |
| `lat` | Yes | Latitude for the search location |
| `lng` | Yes | Longitude for the search location |
| `radius_km` | No | Search radius in kilometers |
| `min_price` | No | Minimum listing price |
| `max_price` | No | Maximum listing price |
| `count` | No | Number of listings to return |
| `sort_by` | No | Sort order Enum: suggested, distance\_ascend, creation\_time\_descend, price\_ascend, price\_descend. |
| `delivery_method` | No | Delivery filter Enum: all, local\_pickup, shipping. |
| `condition` | No | Condition filter Enum: new, used\_like\_new, used\_good, used\_fair. |
| `date_listed` | No | Date listed filter Enum: all, 1, 7, 30, last\_24\_hours, last\_7\_days, last\_30\_days. |
| `availability` | No | Availability filter Enum: available, sold, all. |
| `cursor` | No | Opaque pagination cursor returned from the previous response. Pass it back as-is. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/facebook/marketplace/search?query=example&lat=example&lng=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
