Fetches posts from a public Facebook group, limited to 3 posts per page due to API limitations. Each post includes id, text, url, reactionCount, commentCount, publishTime, videoDetails, and topComments. Supports sorting by TOP_POSTS, RECENT_ACTIVITY, CHRONOLOGICAL, or CHRONOLOGICAL_LISTINGS, with cursor-based pagination.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/facebook/group/posts
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | No | The URL of the group |
| `group_id` | No | The ID of the group |
| `sort_by` | No | How to sort the posts Enum: TOP_POSTS, RECENT_ACTIVITY, CHRONOLOGICAL, CHRONOLOGICAL_LISTINGS. |
| `cursor` | No | The cursor to paginate to the next page |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/facebook/group/posts" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
