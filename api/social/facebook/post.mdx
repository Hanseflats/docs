Retrieves a single public Facebook post or reel by URL. Returns post\_id, like\_count, comment\_count, share\_count, view\_count, description, creation\_time, and author details. For some reels, Facebook does not expose the same view count on the individual post page that it shows on the profile Reels grid. This value can be null or lower than the public Reels badge. If you need the public Reel badge count, call /v1/facebook/profile/reels with the author URL and match the reel by post\_id. For video posts, includes video sd\_url, hd\_url, thumbnail, and length\_in\_second. Optionally fetches comments and transcript via get\_comments and get\_transcript parameters.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/facebook/post
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | Yes | The URL of the post to get |
| `cache_max_age` | No | If we have a response in the cache that is this many days old or newer, return the cached response (0 credits, with 'cached': true and a 'cached\_at' timestamp). Otherwise, scrape a live result (1 credit). [See the Caching page for details.](https://docs.scrapecreators.com/caching) Enum: 1d, 3d, 7d, 14d, 30d. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/facebook/post?url=https://example.com" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
