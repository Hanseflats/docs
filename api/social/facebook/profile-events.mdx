Get the events of a public Facebook page

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/facebook/profile/events
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | Yes | The URL of the public Facebook page |
| `cursor` | No | The cursor to paginate to get more events |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/facebook/profile/events?url=https://example.com" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
