Search for events by name. You can take a look at the page from Facebook we are getting the data from [here](https://www.facebook.com/events/search/?q=dogs)

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/facebook/events/search
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `query` | Yes | The query to search for |
| `cursor` | No | The cursor to paginate to the next page |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/facebook/events/search?query=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
