Fetches details for a Facebook Marketplace item by item id or Marketplace item URL, including title, description, price, location, condition, photos, seller, and availability flags. Rental listings can include listing\_date\_text and availability\_text from Facebook's Marketplace GraphQL response, for example 'Listed over a week ago' and 'Available now'. creation\_time can still be null when Facebook does not expose an exact timestamp.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/facebook/marketplace/item
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `id` | No | Facebook Marketplace item id |
| `url` | No | Facebook Marketplace item URL |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/facebook/marketplace/item" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
