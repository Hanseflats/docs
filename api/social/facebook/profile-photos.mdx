Fetches photos from a public Facebook page with pagination support. Each photo includes photo\_id, accessibility\_caption, viewer\_image with uri, height, and width, plus a thumbnail and direct url. Pagination requires passing both next\_page\_id and cursor from the previous response.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/facebook/profile/photos
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | Yes | Facebook page URL |
| `next_page_id` | No | To paginate through to the next page |
| `cursor` | No | To paginate through to the next page |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/facebook/profile/photos?url=https://example.com" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
