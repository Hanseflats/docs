Searches Facebook Marketplace locations/cities and returns coordinates you can use with the Marketplace Search endpoint.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/facebook/marketplace/location/search
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `query` | Yes | Location search query |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/facebook/marketplace/location/search?query=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
