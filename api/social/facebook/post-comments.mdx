Fetches comments from a Facebook post or reel with cursor-based pagination. Each comment includes id, text, created\_at, reply\_count, reaction\_count, and author details with name and profile\_picture. Passing a feedback\_id instead of a url significantly speeds up the request.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/facebook/post/comments
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | No | Facebook post URL (or reel URL) |
| `feedback_id` | No | Using feedback\_id (instead of url) will _really_ speed up the request. You can get the feedback\_id when you make a request to /v1/facebook/post. |
| `cursor` | No | Cursor to get more comments. Get 'cursor' from previous response. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/facebook/post/comments" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
