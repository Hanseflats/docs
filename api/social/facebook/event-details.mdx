Get a specific event by its URL or id

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/facebook/event/details
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `id` | No | The ID of the event |
| `url` | No | The URL of the event |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/facebook/event/details" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
