Extracts the transcript text from a Facebook video post or reel. Returns the transcript as a single text string with line breaks. Only works on videos under 2 minutes in length.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/facebook/post/transcript
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | Yes | Facebook post URL |
| `cache_max_age` | No | If we have a response in the cache that is this many days old or newer, return the cached response (0 credits, with 'cached': true and a 'cached_at' timestamp). Otherwise, scrape a live result (1 credit). [See the Caching page for details.](https://docs.scrapecreators.com/caching) Enum: 1d, 3d, 7d, 14d, 30d. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/facebook/post/transcript?url=https://example.com" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

**0.5 Lens credits** per upstream credit charged (~**2¢** typical). Cache hits are **free**.
