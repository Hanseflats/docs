Get the events of a city. Check out this [link](https://www.facebook.com/events/explore/saint-petersburg-florida/111326725552547) for an example of where we are getting the data from.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/facebook/events
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | Yes | The URL of the city's Facebook Events page |
| `time` | No | The time frame to search for. Defaults to all time Enum: today, this\_week, next\_week. |
| `cursor` | No | The cursor to paginate to the next page |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/facebook/events?url=https://example.com" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
