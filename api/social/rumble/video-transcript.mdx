Gets a Rumble video's transcript when captions are available. If Rumble does not expose captions for the video, transcript will be null and you will not be charged.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/rumble/video/transcript
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | Yes | Rumble video URL. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/rumble/video/transcript?url=https://example.com" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Credits

**0.5 Lens credits** per upstream credit charged (~**2¢** typical). Cache hits are **free**.

See [Social API overview](/api/social) and [Rumble](/api/social/rumble).
