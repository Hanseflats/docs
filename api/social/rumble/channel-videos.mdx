Gets videos from a Rumble channel by handle or URL. Returns channel metadata, videos, shorts, and a numeric cursor for the next page.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/rumble/channel/videos
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `handle` | No | Rumble channel handle. If you'd prefer to use the URL instead, use the url parameter. |
| `url` | No | Rumble channel URL. If you'd prefer to use the handle instead, use the handle parameter. |
| `cursor` | No | Cursor from the previous response. This is the next page number, like 2 or 3. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/rumble/channel/videos" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
