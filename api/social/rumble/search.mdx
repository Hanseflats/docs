Searches Rumble videos by keyword. Returns matching videos and shorts with title, URL, thumbnail, channel, published date, viewCountText, viewCountInt, and a numeric cursor for the next page.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/rumble/search
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `query` | Yes | Search query. |
| `cursor` | No | Cursor from the previous response. This is the next page number, like 2 or 3. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/rumble/search?query=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
