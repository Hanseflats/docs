Gets Rumble video details by URL. Returns title, description, thumbnail, channel, publish date, view count, likes, dislikes, captions, and media metadata when available.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/rumble/video
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | Yes | Rumble video URL. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/rumble/video?url=https://example.com" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
