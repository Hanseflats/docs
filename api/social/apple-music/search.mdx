Searches Apple Music and returns public result sections for artists, albums, songs, playlists, stations, and music videos. Use type=song, album, artist, playlist, or all.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/apple-music/search
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `query` | Yes | Search query |
| `type` | No | Result type to return. Use all, song, album, artist, playlist, station, music\_video, or radio\_episode. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/apple-music/search?query=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
