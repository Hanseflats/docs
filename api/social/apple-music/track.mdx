Retrieves public Apple Music song details by id or URL. Album track URLs with an i= song id are supported.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/apple-music/track
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `id` | No | Apple Music song id. Some songs have standalone song URLs; for album tracks, use the url parameter. |
| `url` | No | Apple Music song URL or album track URL. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/apple-music/track" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
