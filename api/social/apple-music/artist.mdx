Retrieves public Apple Music artist details, including artwork, editorial notes, top songs, albums, music videos, playlists, and related sections.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/apple-music/artist
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `id` | No | Apple Music artist id. If you'd prefer to use the URL instead, you can use the url parameter instead. |
| `url` | No | Apple Music artist URL. If you'd prefer to use the id instead, you can use the id parameter instead. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/apple-music/artist" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
