Retrieves public Apple Music album details, including title, artist, artwork, release info, tracks, and more by the artist.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/apple-music/album
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `id` | No | Apple Music album id. If you'd prefer to use the URL instead, you can use the url parameter instead. |
| `url` | No | Apple Music album URL. If you'd prefer to use the id instead, you can use the id parameter instead. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/apple-music/album" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
