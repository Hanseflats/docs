Fetches tweets posted within a Twitter/X Community by URL. Returns an array of tweets, each with id, full\_text, view\_count, favorite\_count, retweet\_count, reply\_count, bookmark\_count, quote\_count, created\_at, and source. Each tweet includes a user object with the author's name, screen\_name, avatar, followers\_count, and is\_blue\_verified status.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/twitter/community/tweets
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | Yes | Community URL |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/twitter/community/tweets?url=https://example.com" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
