Retrieves details about a Twitter/X Community by URL. Returns the community name, description, rest\_id, join\_policy, created\_at, member\_count, rules, and creator\_results with the creator's profile. Also includes members\_facepile\_results with avatar images of recent members.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/twitter/community
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | Yes | Community URL |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/twitter/community?url=https://example.com" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
