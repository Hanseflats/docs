Fetches public data for a Snapchat Spotlight video by URL. Returns the snap id, description, creator, engagement counts, thumbnail, and content URL when Snapchat exposes them publicly.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/snapchat/spotlight
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | Yes | Snapchat Spotlight URL. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/snapchat/spotlight?url=https://example.com" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
