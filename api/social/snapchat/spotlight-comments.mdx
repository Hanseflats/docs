Fetches public comments from Snapchat's Spotlight comments API by URL. Returns the snap id, comments, a cursor for the next page, and hasMore. Pass the returned cursor back as the cursor param to load more comments.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/snapchat/spotlight/comments
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | Yes | Snapchat Spotlight URL. |
| `cursor` | No | Pagination cursor from the previous response. |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/snapchat/spotlight/comments?url=https://example.com" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
