Fetches detailed data for a Kick clip by URL, including video, metadata, and channel info. Returns clip id, title, clip\_url, thumbnail\_url, video\_url, view\_count, likes\_count, duration, privacy status, and is\_mature flag. Also includes category details (name, slug), creator info (username), and channel info (username, profile\_picture).

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/kick/clip
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `url` | Yes | Kick clip URL |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/kick/clip?url=https://example.com" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
