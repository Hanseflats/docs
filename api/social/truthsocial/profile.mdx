Retrieves a Truth Social user's public profile including display\_name, username, avatar, header, followers\_count, following\_count, statuses\_count, verified status, website, and created\_at. Only prominent public figures (e.g., Trump, Vance) are accessible without authentication; most other accounts will not work.

## Endpoint

```text
GET https://app.lens.ly/api/v1/social/v1/truthsocial/profile
```

Auth: `Authorization: Bearer YOUR_API_KEY` or `x-api-key`.

## Query parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `handle` | Yes | Truth Social username |

## Example

```bash
curl "https://app.lens.ly/api/v1/social/v1/truthsocial/profile?handle=example" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
