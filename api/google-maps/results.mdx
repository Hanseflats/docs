---
title: "Google Maps results"
sidebarTitle: "Results"
description: "Page structured businesses and contact buckets from a completed scrape."
---

```text
GET https://app.lens.ly/api/v1/google-maps/scrapes/{id}/results?cursor=0&limit=100
```

Returns `409` while the scrape is still running.

## Query params

| Param | Default | Description |
| --- | --- | --- |
| `cursor` | `0` | Offset into the business list |
| `limit` | `100` | Page size (max `100`) |
