---
title: "Poll Google Maps scrape"
sidebarTitle: "Status"
description: "Check scrape and enrichment status until completed."
---

```text
GET https://app.lens.ly/api/v1/google-maps/scrapes/{id}
```

## Response

```json
{
  "scrape_id": "uuid",
  "keyword": "plumber",
  "city": "Austin",
  "state": "TX",
  "status": "completed",
  "max_results": 50,
  "unique_businesses_count": 48,
  "credits_used": 24,
  "estimated_credits": 25,
  "enrichment": {
    "find_owners": true,
    "accept_generic": false
  },
  "error_message": null,
  "created_at": "2026-07-27T12:00:00Z",
  "completed_at": "2026-07-27T12:08:00Z",
  "ready_for_results": true,
  "results": "/api/v1/google-maps/scrapes/uuid/results",
  "download": "/api/v1/google-maps/scrapes/uuid/download"
}
```

## Status values

| Status | Meaning |
| --- | --- |
| `pending` | Queued |
| `scraping` | Pulling Maps results by zip |
| `enriching` | Owner / contact waterfall in progress |
| `completed` | Ready for results / download |
| `failed` | See `error_message` |

Poll every few seconds until `status` is `completed` or `failed`, then call [Results](/api/google-maps/results).

## List scrapes

```text
GET https://app.lens.ly/api/v1/google-maps/scrapes?limit=20
```

Returns recent scrapes for the API key user.
