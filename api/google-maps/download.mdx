description: "Export the full scrape as CSV or JSON."
---

```text
GET https://app.lens.ly/api/v1/google-maps/scrapes/{id}/download?format=csv
GET https://app.lens.ly/api/v1/google-maps/scrapes/{id}/download?format=json
```

Returns the **entire** dataset (not paginated). Use [Results](/api/google-maps/results) when you want cursor paging.

## Query params

| Param | Default | Description |
| --- | --- | --- |
| `format` | `csv` | `csv` or `json` |

## CSV (`format=csv`)

Returns `text/csv` with `Content-Disposition: attachment`.

| Column | Description |
| --- | --- |
| `place_id`, `title`, `website`, `address`, `category` | Maps listing |
| `rating`, `reviews_count`, `google_maps_url`, `zip_code` | Listing meta |
| `owner_first_name`, `owner_last_name` | Owner when found |
| `first_email`, `email_preference` | Ranked email \+ bucket (`personal` / `business` / `role`) |
| `emails_personal`, `emails_business`, `emails_role` | Semicolon-separated buckets |
| `phone`, `phone_mobile`, `first_phone` | Business / mobile / ranked |
| `enrichment_method` | How contacts were found |

```bash
curl -L "https://app.lens.ly/api/v1/google-maps/scrapes/SCRAPE_ID/download?format=csv" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -o austin-plumbers.csv
```

## JSON (`format=json`)

Returns `application/json` with every business in the same shape as [Results](/api/google-maps/results):

```json
  "scrape_id": "uuid",
  "status": "completed",
  "keyword": "plumber",
  "city": "Austin",
  "state": "TX",
  "total": 48,
  "credits_used": 24,
  "businesses": [
    {
      "place_id": "ChIJ…",
      "title": "Acme Plumbing",
      "owner": { "first_name": "Jane", "last_name": "Doe" },
      "emails": {
        "personal": ["jane@gmail.com"],
        "business": [],
        "role": ["info@acmeplumbing.com"],
        "first": "jane@gmail.com",
        "first_type": "personal"
      },
      "phones": {
        "business": "+1 512-555-0100",
        "mobile": null,
        "first": "+1 512-555-0100"
      }
    }
  ]
}
```

```bash
curl -L "https://app.lens.ly/api/v1/google-maps/scrapes/SCRAPE_ID/download?format=json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -o austin-plumbers.json
```
