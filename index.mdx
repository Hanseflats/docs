Lens provides prepaid APIs for company enrichment, audience building, structured [scrapers](/api/scrapers), and the [Social API](/api/social) (Instagram, TikTok, LinkedIn, and more).

## Base URL

```text
https://app.lens.ly
```

## OpenAPI & discovery

Machine-readable API specs (no auth):

- [OpenAPI 3.1](https://app.lens.ly/openapi.json) — `https://app.lens.ly/openapi.json`
- [APIs.json](https://app.lens.ly/apis.json) — `https://app.lens.ly/apis.json`

## Authentication

All authenticated requests require:

```text
Authorization: Bearer YOUR_API_KEY
```

Or:

```text
x-api-key: YOUR_API_KEY
```

## Quick example

```bash
curl -X POST https://app.lens.ly/api/v1/company/mobile-app \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"domains":["stripe.com","notion.so"]}'
```

## For AI agents

Start at [`/llms.txt`](https://app.lens.ly/llms.txt) or [`GET /api/v1/meta`](/agents/meta), then register → verify → billing setup. See [Agent self-serve](/agents/overview).

## Credits

Most enrichment calls cost **3 credits** (3¢ at 1¢/credit) against your prepaid billing balance. Social API calls cost **0.5 credits** per upstream credit (~2¢ typical; cache hits free). See [Credits & Pricing](/guides/credits).
